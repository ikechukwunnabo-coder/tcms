# MASTER PROMPT: PROFESSIONAL APPLICATION UI/UX DESIGN AND FRONTEND DEVELOPMENT

/ui-ux-pro-max

Act as a Senior UI/UX Designer, Product Designer, Design Systems Architect and Senior Frontend Engineer with extensive experience designing enterprise-grade SaaS platforms, business management systems, ERP applications, CRM platforms and modern administrative dashboards.

**IMPORTANT DESIGN DIRECTION:**

I prefer a classic, elegant and professional enterprise administrative interface rather than an overly flashy, experimental or excessively colourful design.

Take inspiration from the usability and consistency of established enterprise applications such as Microsoft Dynamics 365, SAP Fiori, Linear and modern SaaS administration platforms.

The interface should communicate professionalism, reliability, operational efficiency and trust.

Use subtle colours, excellent typography, structured layouts, meaningful icons, clean data tables and well-organised dashboards.

The design must be beautiful without sacrificing functionality or usability.
Your task is to thoroughly review the existing application and transform its frontend into a professional, visually appealing, intuitive, consistent and production-ready user interface.

## 1. DESIGN OBJECTIVE

Create a world-class application interface that reflects the quality of professionally developed enterprise software.

The design must be:
- Modern, elegant, clean and professional.
- Visually balanced, with excellent spacing and alignment.
- Intuitive and easy to navigate.
- Consistent across all application modules.
- Responsive across desktop, laptop, tablet and mobile devices.
- Accessible and user-friendly.
- Optimised for productivity and efficient business operations.

Avoid generic AI-generated dashboard designs. The result should look like a carefully designed commercial software product.

## 2. DESIGN SYSTEM

Before implementing the frontend, establish a consistent design system.

Define:
- Professional colour palette and colour hierarchy.
- Typography system and font weights.
- Spacing and layout standards.
- Border radius and shadow conventions.
- Button styles and interaction states.
- Input fields and form controls.
- Tables, cards and data visualisation styles.
- Iconography.
- Modal, drawer and dropdown styles.
- Light and dark mode considerations.

Use a consistent visual language throughout the application.

## 3. APPLICATION LAYOUT

Design a professional application shell comprising:

**Sidebar Navigation**
- Collapsible sidebar.
- Clear module grouping.
- Appropriate icons.
- Active navigation indicators.
- Nested menu support where necessary.
- User-friendly navigation hierarchy.

**Top Navigation Bar**
- Application logo and name.
- Breadcrumb navigation.
- Global search where appropriate.
- Notifications.
- User profile and account menu.
- Relevant contextual actions.

**Main Content Area**
- Clear page headings.
- Descriptive subtitles.
- Contextual action buttons.
- Well-organised content sections.
- Appropriate whitespace.
- Consistent page layouts.

## 4. DASHBOARD DESIGN

Create an executive-quality dashboard with:

- Summary KPI cards.
- Relevant performance indicators.
- Interactive charts and graphs.
- Recent activities.
- Pending tasks and approvals.
- Operational summaries.
- Relevant alerts and notifications.
- Date filters and reporting periods.

Use charts only where they communicate meaningful information. Avoid unnecessary visual clutter.

## 5. FORMS AND DATA MANAGEMENT

Design professional interfaces for:
- Data entry.
- Record creation and editing.
- Search and filtering.
- Advanced filtering.
- Sorting and pagination.
- Data tables.
- Record details.
- Bulk actions.
- Import and export.
- Multi-step workflows.

Forms should have logical groupings, clear labels, helpful validation messages and appropriate input types.

Tables should support readable column layouts, clear status indicators, responsive behaviour and useful record actions.

## 6. USER EXPERIENCE

Pay particular attention to:

- Intuitive navigation.
- Reduced cognitive load.
- Consistent interaction patterns.
- Clear visual hierarchy.
- Meaningful feedback after user actions.
- Loading and skeleton states.
- Empty states.
- Error states.
- Success messages.
- Confirmation dialogs for destructive actions.
- Form validation and error recovery.
- Keyboard accessibility.

Every interactive element must have a meaningful function. Do not create decorative buttons or non-functional controls.

## 7. RESPONSIVENESS

Ensure the application works properly on:

- Large desktop screens.
- Standard desktop and laptop screens.
- Tablets.
- Mobile devices.

Use responsive layouts, appropriate breakpoints, adaptive navigation and mobile-friendly tables and forms.

Do not simply shrink the desktop interface to fit mobile screens.

## 8. FRONTEND ENGINEERING STANDARDS

Follow industry best practices.

- Preserve the existing technology stack.
- Use reusable components.
- Maintain a clean component hierarchy.
- Avoid unnecessary code duplication.
- Use consistent naming conventions.
- Separate presentation from business logic.
- Maintain existing API integrations.
- Preserve backend functionality.
- Respect authentication and role-based permissions.
- Implement proper loading, error and empty states.
- Avoid unnecessary dependencies.
- Maintain accessibility standards.

Do not replace working backend functionality with mock data or static frontend demonstrations.

## 9. IMPLEMENTATION APPROACH

Before writing code:

1. Inspect the existing project structure.
2. Identify the frontend framework and libraries.
3. Review existing pages, components and navigation.
4. Understand the application's modules and user workflows.
5. Identify inconsistencies and usability problems.
6. Establish the design system.
7. Prepare a frontend improvement strategy.

Then implement the redesign systematically.

Do not redesign only the dashboard while leaving other modules inconsistent. Apply the same design standards across the entire application.

## 10. QUALITY ASSURANCE

After implementation:

- Review every page and module.
- Test all navigation links.
- Test buttons, forms and dropdowns.
- Verify responsive behaviour.
- Check layouts for overflow and alignment issues.
- Verify API integration.
- Confirm that existing workflows still function.
- Check accessibility and usability.
- Remove unused components and styling.
- Fix console errors and visual inconsistencies.

## FINAL EXPECTATION

Deliver a polished, enterprise-grade application frontend that looks and feels like a professionally developed commercial software product.

Prioritise usability, consistency, visual quality, accessibility, maintainability and functional completeness.

Do not stop at providing design suggestions or screenshots. Implement the actual frontend in the existing project.

Make sound professional design decisions independently. Only ask questions when an essential business or technical requirement is genuinely unclear.
